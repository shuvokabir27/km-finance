# Kuakata Multimedia Finance (কেএম ফাইন্যান্স)

কুয়াকাটা মাল্টিমিডিয়ার সম্পূর্ণ স্ট্যান্ডঅ্যালোন ফাইন্যান্সিয়াল, টিম ও বেতন ব্যবস্থাপনা সিস্টেম।

## 🌟 মূল সুবিধাসমূহ (Key Features)

- **ড্যাশবোর্ড (Dashboard)**:
  - লাইভ বকেয়া সারসংক্ষেপ (পূর্বের ও চলতি মাসের বকেয়া)
  - **কুইক অ্যাকশন**: হোম পেজ থেকে সরাসরি ১-ক্লিকে **দ্রুত বকেয়া পরিশোধ** ও **ক্লায়েন্ট পেমেন্ট গ্রহণ**
  - পপআপ মডালে বাইরে ক্লিক করলে ভুলবশত বন্ধ না হওয়ার প্রোটেকশন
  - সম্প্রতি সম্পন্ন শুটিং ও পেমেন্ট হিস্ট্রি
- **সদস্য ব্যবস্থাপনা (Team & Members)**:
  - দৈনিক ও মাসিক সদস্যভিত্তিক হাজিরা ও বেতন হিসাব
  - সদস্যের পেমেন্ট অ্যাকাউন্ট (বিকাশ, নগদ, রকেট, ব্যাংক) সংরক্ষণ
  - সদস্যের পাবলিক প্রোফাইল লিংক ও শেয়ারিং
  - প্রোফাইল ছবি আপলোড (Supabase Storage: `member-photos`)
- **ক্লায়েন্ট হিসাব (Client Dues)**:
  - বাহিরের চ্যানেলের শুটিং চুক্তি, আদায় ও অবশিষ্ট বকেয়া ট্র্যাকিং
  - FIFO স্বয়ংক্রিয় বণ্টন পদ্ধতিতে পুরাতন বকেয়া নিষ্পত্তি
- **শেয়ার চ্যানেল ও অন্যান্য হিসাব**:
  - অংশীদারদের লাভ-ক্ষতি বণ্টন
  - শুটিং খরচ ও সামগ্রিক আর্থিক রিপোর্ট

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Framework**: [TanStack Start](https://tanstack.com/start) (Full-stack React with SSR)
- **Bundler & Server Engine**: Vite + Nitro engine
- **Styling**: Tailwind CSS + Shadcn UI
- **Database & Auth**: Supabase PostgreSQL & Auth
- **Storage**: Supabase Storage (`member-photos`)
- **Hosting Target**: Vercel

## 🚀 লোকাল ডেভেলপমেন্ট (Local Development)

```bash
# ডিপেন্ডেন্সি ইনস্টল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# প্রোডাকশন বিল্ড
npm run build

# লোকাল প্রিভিউ
npm run preview
```

## 🗄️ ডাটাবেস সেটআপ (Database Setup)

Supabase ড্যাশবোর্ডের SQL Editor-এ `supabase/complete_schema.sql` রান করে এক ক্লিকে সম্পূর্ণ স্কিমা, RLS পলিসি ও স্টোরেজ বাকেট ইনিশিয়ালাইজ করতে পারেন।
